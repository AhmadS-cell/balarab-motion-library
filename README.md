# Balarab Motion Library | مكتبة موشن بالعرب

مكتبة مرجعية لاختيار وبناء الجرافيك موشن للريلز والفيديوهات. تضم **160 معاينة متحركة** و**36 مصدر GitHub** و**20 وصفة مشهد أساسية**. أسماء المكتبات والمصطلحات بالإنجليزي، والشرح وتقييم الملاءمة بالعربي مع أولوية العربية وRTL. تضم أيضًا مصادر أجنبية شائعة تستحق الدراسة حتى إن احتاجت إعادة بناء.

## شاهد الموشن واطلبه باسمه

[افتح المعرض العام](https://balarab-motion-gallery.ahmadsabbah81.chatgpt.site) — 160 حركة من M001 إلى M160، ضمن 13 فئة، ولكل منها معاينة متحركة واسم عربي وإنجليزي وشرح ورابط مرجع. ابحث وصنف، وافتح المعاينة المكبرة للتشغيل والإيقاف وتحريك الزمن، ثم انسخ طلب الحركة أو رابطها، أو اجمع مختاراتك.

أمثلة: [M013،عداد يرتفع ويستقر](https://balarab-motion-gallery.ahmadsabbah81.chatgpt.site/#motion=M013)، [M037،ضغط ثم نتيجة](https://balarab-motion-gallery.ahmadsabbah81.chatgpt.site/#motion=M037)، [M049،انتقال تكلفة من الطلب](https://balarab-motion-gallery.ahmadsabbah81.chatgpt.site/#motion=M049). المعاينات تنفيذ أصلي توضيحي لبالعرب، وليست لقطات demos المصادر أو دليل نسخ كودها. العمق التوضيحي2.5D. التوقيت والأرقام أمثلة تتكيف مع التسجيل الفعلي عند إنتاج ريل.

المصدر الكامل في [gallery](gallery/README.md)، وفهرس الحركات القابل للاستخدام في الإنتاج في [motion-previews.json](motion-previews.json).

المصادر موثقة بتاريخ **14 أكتوبر 2026** من GitHub وREADME الرسمي. النجوم مؤشر اهتمام بالمشروع، وليست إثباتًا أن مشاهدي الريلز يحبون تأثيرًا أو أنه يحسن الاحتفاظ. التصنيفات اقتراحات تحريرية؛ المكونات لم تختبر في تصدير عربي بعد.

## اختيارات البداية

| الحاجة | مصادر مرشحة | سبب الاختيار |
| --- | --- | --- |
| فيديو كامل وتوقيت كابتشن وصوت | Remotion | تحكم بالإطار وDOM مناسب لتجربة العربية |
| شرح رسومي متصل | Motion Canvas | بناء حركات تفسيرية ومزامنتها بالتعليق |
| تتابع وإعادة توزيع العناصر | GSAP، Anime.js | مسارات وحالات ومرجع قوي لسلاسة الحركة |
| قطع جاهزة للفيديو | Onda، Curvable Motion، Remotion Scenes | كشف وأرقام وواجهات قابلة للتكييف |
| إلهام شائع للواجهات | React Bits، Magic UI، Motion Primitives | تنوع، مع اختيار الوظيفة وتغيير الهوية والتوقيت |
| حسابات وعلاقات | Manim | بناء خطوة ثم قيمتها ثم أثرها في الحسبة |
| منتج يحتاج عمقًا | Three.js، React Three Fiber، Drei | زاوية وإضاءة وكاميرا عندما تخدم المنتج |

هذا ترتيب تجربة بحسب الحاجة، لا تبديل إلزامي لأداة الإنتاج الحالية. خذ السلوك المناسب وابنه في المسار القائم إذا كان تغيير المحرك يزيد التعقيد.

## بحث محلي دون تثبيت حزم

يتطلب Node.js فقط، ولا يثبت أو يشغل كود أي مكتبة خارجية.

```sh
node scripts/find.mjs comparison
node scripts/find.mjs "العربية"
node scripts/find.mjs --category scene-pack
node scripts/find.mjs --priority core
node scripts/find.mjs counter --json
node scripts/find.mjs --patterns "العميل"
node scripts/find.mjs --previews "M049"
node scripts/validate.mjs
```

## سياسة الاستخدام

اختر الحركة من معنى الفقرة والدليل الذي يقدمه المشهد. الهوك كامل من أول فريم، وكلام ناصر هو التفسير الأساسي على سطر واحد، مع هايلايت الكلمة المنطوقة من التوقيت الحقيقي. الواجهة موبايل RTL بلا إطار هاتف. الموقع ثابت أسفل اليسار واللوجو الأصلي في الخاتمة. ألوان المصادر وخطوطها ليست براند بالعرب، ولا تختلق أرقامًا أو ميزات للمنصات.

المكتبة تحفظ وصفًا وروابط وبيانات بحث، ولا تعيد توزيع أكواد أو أصول المصادر. ملفات README التي جمعت للدراسة تبقى محليًا في مجلد research المستبعد من Git. المؤثرات الأصلية وحقوق الصور والخطوط والشعارات تحتاج توثيقًا عند اختيار الأصل الفعلي.

لا يسجل مصدر جاهزًا للإنتاج قبل تجربة عربية 9:16 وفحص التصدير والحركة المتصلة والصوت. إدراجه هنا لا يعني إنتاج ريل أو اعتماده أو نشره. لا تحديث دوري تلقائي؛ يعاد التحقق عند اختيار حزمة أو أصل للإنتاج.

## توسعة الحركة السلسة ومرجع الفيديو

أضيفت M121 إلى M138 من 18 مثالًا محددًا في Anime.js وReact Spring بترخيص MIT، وأضيفت M139 إلى M144 من سلوك مرئي في فيديو المرجع، مع ربط طابور الإشعارات M136 به أيضًا. [الأمثلة والكود](research/motion-example-bindings.json) و[التوثيق المرئي](research/reference-video-methods.json). كل الرسم العربي أصلي، ومؤشرات النجوم والفوركس تخص المستودعات. صور المرجع وفيديوه لا يرفعان إلى المعرض أو المستودع.


تحديث Prompt Motion:16 معاينة جديدة و8 معاينات مطورة و6 روابط مرجعية إضافية. افتح فئة «من Prompt Motion» في المعرض، أو اطلب M145 إلى M160. التنفيذ عربي أصلي مع اعتماد صاحب كل مثال؛ لا تنقل حقوق المصدر تلقائيًا إلى المكتبة.
