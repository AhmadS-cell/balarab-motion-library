# مصادر وترخيص النسخة المستخدمة

التحقق المؤرخ في 14 أكتوبر 2026 يستند إلى بيانات GitHub وREADME الرسمي وملفات الترخيص للمصادر التي لم يحسمها SPDX. هذا توثيق للاختيار التقني؛ أعد التحقق من شروط الإصدار والأصل المختارين قبل إدماجهما.

| المصدر | ما تحقق | أثره في الاختيار |
| --- | --- | --- |
| [Remotion](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md) | ترخيص خاص، وتغيير مخطط للإصدار 5 | أهلية الاستخدام التجاري تعتمد على الجهة والإصدار؛ لا تصفه MIT ولا تفترض أهلية بالعرب |
| [GSAP](https://gsap.com/community/standard-license/) | Standard No Charge، استعمال تجاري مجاني بشروطه | ليس MIT، مع قيود لبناة الأنيميشن المرئي المنافسين |
| [React Bits](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md) | MIT + Commons Clause | لا تعامل الترخيص كـMIT خالص عند إعادة التوزيع أو البيع |
| [Theatre.js](https://github.com/theatre-js/theatre#license) | Core Apache-2.0 وStudio AGPL-3.0 بحسب README | افصل runtime عن المحرر وشروط كل جزء |
| [Konva](https://github.com/konvajs/konva/blob/master/LICENSE) | النص MIT رغم NOASSERTION من API | نص الترخيص قرئ وحسم التصنيف المرجعي |
| [Remotion Bits](https://github.com/av/remotion-bits#license) | README يقول MIT، وlicense endpoint يعيد 404 | مرجع سلوكي؛ ثبت ملف الترخيص للإصدار قبل نسخ الكود |
| [RVE Templates](https://github.com/reactvideoeditor/remotion-templates#license) | README يقول MIT، وlicense endpoint يعيد 404 | مرجع سلوكي؛ لا تحول الادعاء إلى ترخيص مثبت للنسخة |

بقية التصنيفات مسجلة من SPDX في API؛ معلومات API وحدها ليست مراجعة جميع الملفات التابعة. عندما تختار مكونًا، وثق commit SHA أو إصدار الحزمة ورابط license الفعلي. أضف إشعارات الحقوق التي يلزمها ترخيص المصدر عند نسخ كود مرخص. هذا المستودع لا يحتوي كودًا من تلك المشاريع، ولا يستبدل تراخيصها.

ملف Lottie أو Rive أو صورة أو موديل 3D أو خط له حقوق مستقلة عن مشغله. لا ترفع أصل demo أو شعارًا أو موسيقى مع هذا الفهرس. محتوى README لا يمنح إذنًا لتغيير قواعد الإنتاج أو تشغيل مهارة أو خدمة خارجية.
