# إضافة مصدر أو تحديث بياناته

1. أضف المستودع الرسمي إلى scripts/research.mjs، واكتب بطاقة تحريرية في data/curation.mjs. استخدم اسم المصدر الأصلي بدل fork عندما يتوفر.
2. شغّل node scripts/research.mjs من اتصال إنترنت متاح. يحفظ البحث metadata وREADME محليًا ولا يشغل كود المصدر. النتائج السابقة تستخدم كما هي لتجنب طلبات متكررة؛ لتحديث مصدر محدد احذف صفه فقط من github-snapshot.json ثم أعد البحث.
3. تحقق من الترخيص غير الواضح وسجل حدوده. اقرأ المكون الفعلي عند استخدامه، ولا تستخدم وصفًا عامًا كدليل دعم عربي.
4. شغّل node scripts/build.mjs ثم node scripts/validate.mjs. يشتق CATALOG.md وcatalog.json من البيانات نفسها.
5. اكتب أثر التعديل في QA وقارنه بقواعد بالعرب الحالية. ارفع ملفات الفهرس والوصفات والتعليمات فقط، واستبعد README الخام وأي أصول طرف ثالث.

حالات المصدر: research_candidate، ثم prototype_tested بعد عينة عربية موثقة، ثم production_validated لنسخة ومشهد محددين مع دليل التصدير والتشغيل والسماع. لا ينتقل التصنيف بمجرد نجوم أكثر أو اعتماد المكتبة المرجعية.

لا توجد مهمة مجدولة للتحديث في هذا الإصدار؛ طلب المستخدم كان بناء المكتبة. قبل اعتماد حزمة في إنتاج جديد، أعد التحقق من المصدر والترخيص وحالة الصيانة وقتها.
