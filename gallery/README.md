# معرض موشن بالعرب

واجهة عامة بمئة وعشرين معاينة متحركة أصلية، من M001 إلى M120، ضمن عشر فئات. أسماء عربية وإنجليزية، بحث وتصنيف ومختارات محلية، مشغل بتوقيت يمكن تحريكه، ونسخ طلب الحركة ورابطها المباشر.

المصادر مرتبطة بثلاثة وثلاثين مستودع GitHub موثقًا في sources.json. تنفيذ المعاينات مرسوم أصليًا لهذه المكتبة؛ ليست لقطات من demos المصادر ولا دليل استخدام كودها. العمق توضيحي 2.5D. أرقام المعاينات أمثلة. المكونات يجب تكييفها وفحصها وفق المنطوق والهوية عند إنتاج ريل.

التطبيق buildless ولا يتطلب تثبيت حزم. ملفات الموقع في dist. لمعاينة محلية: node server.mjs. فحص سلامة المعاينات: node check.mjs. ملفات QA محلية مستبعدة من Git.

هذه نسخة مصدر للرجوع إلى الحركات داخل مستودع المكتبة. الموقع العام في https://balarab-motion-gallery.ahmadsabbah81.chatgpt.site. نسخة النشر الرسمية في D:/Balarab/sites/balarab-motion-gallery،ومعرفها في.openapi/hosting.jsonهناك. بيانات اعتماد النشر لا تحفظ في الملفات.
